How to read the path

Cylinders run left to right along the top. Each line down is one move of the head. A shorter, straighter path means less travel and a faster disk.

The edge-travelling algorithms (SCAN, C-SCAN) go all the way to the end of the disk. LOOK and C-LOOK turn around at the last request. Return jumps in C-SCAN and C-LOOK count toward the distance, and duplicate requests cost nothing.

All the maths runs in C (backend/algorithms.c). This page only draws what the engine returns.

FCFS
Serves requests in the order they arrived.
SSTF
Always jumps to the closest waiting request.
SCAN
Sweeps to one edge, then reverses, like an elevator.
C-SCAN
Sweeps to one edge, then returns to the start and sweeps again.
LOOK
Like SCAN, but reverses at the last request instead of the edge.
C-LOOK
Like C-SCAN, but jumps back from the last request.
